Privacy Policy

Last updated: 2026-11-08

Who uses Jarvis

Jarvis is a personal desktop application with a single user: its developer, Barnabas Juhasz. It is not offered to anyone else.

Google data Jarvis accesses

Jarvis requests only these read-only Google scopes, and only for the developer's own Google account:

  • Gmail, read only
  • Google Health, read only
  • openid and email, to identify which of his own accounts is signed in

Jarvis never sends, modifies or deletes email or health data.

How the data is used and stored

Data is fetched directly from Google to the developer's own computer and cached there only, so that he can read and search it in Jarvis. It is not uploaded to any server operated for Jarvis.

Google user data is never sold, shared with or transferred to third parties, never used for advertising, and never used to develop, improve or train AI or machine-learning models.

OAuth tokens

OAuth tokens are stored locally on the developer's computer. Access can be revoked at any time at myaccount.google.com/permissions; deleting the local cache removes the stored data.

Limited Use

Jarvis's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
